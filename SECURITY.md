# Security policy

MarkDesk is an unaudited hackathon prototype. Do not deposit meaningful value.

Please report vulnerabilities privately to the repository maintainers rather than opening a public issue. Include reproduction steps, affected commit, impact, and a suggested fix when possible.

## Known incomplete areas

- Token-2022 transfer hooks and transfer-fee net accounting
- Publisher key custody and rotation
- Asset allowlisting and issuer restriction checks
- End-to-end adversarial tests against a local validator
- Independent smart-contract audit

See [`docs/THREAT_MODEL.md`](docs/THREAT_MODEL.md) for the current trust model.
